# 🦷 Bright Smile Dental Clinic

A modern and responsive dental clinic website built with **HTML5** and **CSS3**, designed to provide a clean, professional, and user-friendly experience for patients.

The project focuses on creating a modern dental clinic interface while practicing **structured HTML, organized CSS, responsive layouts, typography, spacing, Flexbox, CSS Grid, and media queries**.

## ✨ Features

* Responsive and modern navigation bar
* Responsive mobile navigation menu
* Full-screen Hero / Landing section
* Dental clinic introduction and call-to-action
* Services section with dental treatment cards
* Doctors section featuring clinic specialists
* Pricing section for dental treatments
* Testimonials section
* Responsive dental gallery
* Contact Us section
* Simple and clean Footer
* Smooth scrolling navigation
* Hover effects and transitions
* Responsive layouts for different screen sizes
* Professional dental clinic design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Flexbox**
* **CSS Grid**
* **Media Queries**
* **Font Awesome**
* **Google Fonts**
* **Normalize.css**

## 🦷 Main Sections

### 🏠 Home

A modern landing section introducing the dental clinic with a professional dental image and a clear call-to-action.

### 🩺 Services

Showcases the clinic's main dental services through clean and responsive cards.

### 👨‍⚕️ Doctors

Introduces the clinic's specialists along with their dental specialties.

### 💰 Pricing

Displays selected dental treatments and their prices in an organized and easy-to-read layout.

### ⭐ Testimonials

Highlights patient feedback and experiences to create trust and credibility.

### 🖼️ Gallery

A responsive gallery showcasing the clinic, dental treatments, equipment, doctors, and patient experiences.

### 📞 Contact

Provides visitors with the necessary information to contact and reach the dental clinic.

### 🦷 Footer

A simple and responsive footer containing essential navigation and clinic information.

## 📱 Responsive Design

The website is designed to provide a consistent experience across different screen sizes:

* **Desktop** — Full navigation and multi-column layouts
* **Tablet** — Adjusted spacing, typography, and responsive card layouts
* **Mobile** — Mobile navigation, stacked sections, and optimized content
